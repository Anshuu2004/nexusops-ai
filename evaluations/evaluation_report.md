## How a scenario passes

Final status, the exact set of tickets created in the mock ERP, and the exact set of notifications sent must all equal the oracle's expectation. A duplicated ticket or notification fails the scenario.

## Limitations

- Synthetic scenarios against an in-process mock ERP; expected outcomes come from an independent oracle in scenarios.py, generated before any run.
- naive/retry_only are weaker baselines implemented in this repo, not third-party systems.
- The planner used is the deterministic RulePlanner; no LLM accuracy is measured here.
